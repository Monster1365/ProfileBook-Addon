# ProfileBook-Addon

> Minecraft Bedrock Edition용 플레이어 프로필 애드온

![Version](https://img.shields.io/badge/version-v1.0.1-blue)

## 소개

ProfileBook은 플레이어의 프로필을 확인하고 관리할 수 있는 마인크래프트 베드락 에디션 애드온입니다.

플레이어는 ProfileBook을 통해 자신의 정보를 기록하거나 다른 플레이어의 프로필을 확인할 수 있습니다. 서버, 멀티플레이, RPG 맵, 커뮤니티 월드 등에서 활용할 수 있도록 제작되었습니다.

---

## 주요 기능

- 플레이어 프로필 확인
- 프로필 북(Book) 인터페이스 제공
- 다른 플레이어 정보 조회
- 데이터 저장 및 불러오기
- Minecraft Bedrock Edition 지원

---

## 설치 방법

1. `ProfileBook-v1.0.1.mcaddon` 파일을 다운로드합니다.
2. 파일을 실행하여 Minecraft에 가져옵니다.

---

## 사용 방법

명령어를 통해 아이템 획득
